# Lifeboat privacy policy

Lifeboat is a personal, self-hosted backup tool written and used by one person (Simon Reid) on their own server.

**What it accesses.** With the `drive.file` permission, Lifeboat can only see files and folders that it created itself in the signed-in person's own Google Drive. It cannot see any other file in the Drive.

**What it does with that access.** It uploads backup files from the owner's own server to the owner's own Drive, and deletes its own old backups. Nothing else.

**Where data goes.** Google sign-in tokens are stored only on the owner's server. Nothing is sent to any third party, no analytics are collected, and no data is sold or shared.
